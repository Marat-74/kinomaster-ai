Поддерживаются произвольные названия частей и родительские связи. Это основа для разных типов анатомии: человек, птица, четвероногое и фантастическое существо.

Формат передачи от будущего ИИ-анализатора

Анализатор должен будет автоматически создать слои, определить pivots и связи parent/child, а затем передать этот JSON вместе с PNG-файлами в PixiJS.





PixiJS подключается из официального CDN. Для работы необходим интернет. Модуль не отправляет изображения на сервер и не требует SYNTX.
