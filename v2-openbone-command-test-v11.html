Подготовка загрузки движка…

Загружается демонстрационный персонаж из открытого проекта OpenBone. У него уже есть скелет, 22 кости, анимации ходьбы, атаки и приветствия, а также звуковые эффекты.

Проверка управления обычным текстом

Напиши команду по-русски. Сейчас это небольшой тестовый словарь, а не полноценное понимание свободного сценария.

«Рыцарь идёт» «Остановись» «Поздоровайся» «Атакуй»
Команда ещё не отправлялась.
Что именно проверяем
  • Загружается ли внешний скелетный 2D-движок в нашей GitHub Pages.
  • Воспроизводятся ли настоящие движения частей тела, а не только изменение чисел.
  • Работают ли переходы между ходьбой, ожиданием, приветствием и атакой.
  • Может ли русский текст управлять реальным персонажем через командный слой.

Важно: этот тестовый рыцарь не Петрович. Успешный тест подтвердит работу движка и командного управления, но не докажет, что наш собственный рисунок уже автоматически разобран на части.
